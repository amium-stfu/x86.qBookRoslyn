## Problem and required behavior

`SetMruByCsvString` splits the input CSV into a `string[]` and enumerates `items.Reverse()` before calling `Add`, which inserts at index zero. The prior Build reported CS1579 at line 122 because the selected expression returns void. The exact method binding was not independently established; the suspected span-extension binding is diagnostic context, not a prerequisite for this correction.

Explicitly select LINQ enumerable reversal. For CSV entries `A,B,C` with sufficient MRU capacity, reverse enumeration visits `C,B,A`; successive front insertions retain `A,B,C` as the resulting MRU order. Keep existing splitting, empty-entry removal, capacity and duplicate handling unchanged. Do not reverse the array in place or iterate forward.

## Complete human-readable write scope

The only maintained file authorized for modification is `qbook/MruFilesManager.cs`, and only the foreach source expression in `SetMruByCsvString` may change.
